## 1. 二叉树的前序遍历

> 用栈来模拟实现递归
>
> 如何访问一棵树
>
> 1. 左路节点 （ 入栈 + 访问 ）
> 2. 这些左路节点的右子树
>
> 如何访问这些右子树呢
>
> - 再把他们分成左路节点和右树迭代来访问
>
>   ![image-20250215141844273](../../../../../AppData/Roaming/Typora/typora-user-images/image-20250215141844273.png)
>
> ```cpp
> /**
>  * Definition for a binary tree node.
>  * struct TreeNode {
>  *     int val;
>  *     TreeNode *left;
>  *     TreeNode *right;
>  *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
>  *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
>  *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
>  * };
>  */
> class Solution {
> public:
>     vector<int> preorderTraversal(TreeNode* root) {
>         vector<int> v;
>         stack<TreeNode*> st;
>         TreeNode* cur = root;
>         while(!st.empty() || cur) {
>             while(cur) {
>                 // 左路节点
>                 v.push_back(cur->val);
>                 st.push(cur);
>                 cur = cur->left;
>             }
>             // 访问右子树
>             TreeNode* top = st.top();
>             st.pop();
>             
>             cur = top->right;
>         }
> 
>         return v;
>     }
> };
> ```
>
> 核心是用栈的数据结构模拟实现栈

## 2. 二叉树的中序遍历

> 1. 左路节点只入栈，不访问
> 2. 取栈中的节点
>
> ```cpp
> class Solution {
> public:
>     vector<int> inorderTraversal(TreeNode* root) {
>         vector<int> v;
>         stack<TreeNode*> st;
>         TreeNode* cur = root;
>         while(cur || !st.empty()) {
>             while(cur) {
>                 // 左路节点，只入栈
>                 st.push(cur);
>                 cur = cur->left;
>             }
> 			
>             // 取栈顶访问
>             TreeNode* top = st.top();
>             st.pop();
>             v.push_back(top->val);
>             cur = top->right;
>         }
> 
>         return v;
>     }
> };
> ```

## 3. 二叉树的后序遍历

> 由于后序遍历要求最后访问根节点，所以当左路节点的右子树不为空的时候，需要区分我们的右子树是否已经访问
>
> 这里我们引入一个（上一个访问的节点）lastNode，用以判断右子树是否已经被访问
>
> ```cpp
> class Solution {
> public:
>     vector<int> postorderTraversal(TreeNode* root) {
>         vector<int> v;
>         stack<TreeNode*> st;
>         // 最后一个访问的节点
>         TreeNode* lastNode = nullptr;
>         TreeNode* cur = root;
>         while(cur || !st.empty()) {
>             while(cur) {
>                 st.push(cur);
>                 cur = cur->left;
>             }
>             TreeNode* top = st.top();
> 			
>             // 取到左路节点
>             // a.如果左路节点的右为空或者上一个最近访问的节点是右子树的根，就说明右子树已经访问了，就可以访问了
>             if(top->right == nullptr || lastNode == top->right) {
>                 v.push_back(top->val);
>                 lastNode = top;
>                 st.pop();
>             }
>             else {
>                 cur = cur->right;
>             }
>         }
>         return v;
>     }
> };
> ```
